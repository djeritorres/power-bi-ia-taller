Preparación del taller

Lo que necesitamos

La IA se conecta al modelo de datos y hace los cambios directamente ahí. No usamos el chat para buscar soluciones ni para copiar y pegar código.

La idea

Tres piezas, una conexión

🤖 Cliente de IA

Claude Desktop, Claude Code o ChatGPT/Codex.

→

🔌 Servidor MCP LOCAL

powerbi-modeling-mcp, de Microsoft. Se conecta directo con el cliente de IA, sin pasar por internet.

→

📊 Tu modelo

Power BI Desktop abierto, una carpeta PBIP o un modelo en Fabric.

El servidor solo modela. Para páginas y visuales del reporte, la IA edita los archivos PBIR del proyecto desde VS Code.

Preview · Power BI Desktop

Power BI Desktop Bridge

  • Es un servidor local dentro del propio proceso de Power BI Desktop: crea un canal directo entre programas de tu compu, sin pasar por internet
  • Deja que un agente recargue el reporte y el modelo después de editar los archivos PBIR/TMDL, sin cerrar ni reabrir Desktop
  • También puede tomar capturas de cada página del reporte, para que la IA "vea" cómo quedó el visual que acaba de crear
  • Se activa en Archivo → Opciones → Seguridad → Desktop Bridge (viene activado por defecto)
# CLI: powerbi-desktop-bridge-cli
powerbi-desktop status
powerbi-desktop manifest
powerbi-desktop reload
powerbi-desktop screenshot-all
reload recarga el PBIR actual; screenshot-all captura cada página del reporte
Esto cierra el hueco que vimos antes: con el Bridge, la IA sí puede confirmar cómo quedó un visual, sin depender de que tú abras Desktop a revisar.
Opción A · Claude Desktop

Claude Desktop

  • Claude Desktop también se conecta directo a servidores MCP que viven en tu compu, igual que VS Code
  • Abre el archivo de configuración: macOS en ~/Library/Application Support/Claude/, Windows en %APPDATA%\Claude\
  • Añade el servidor dentro de mcpServers y reinicia Claude Desktop
  • El ícono de herramientas (🔨) junto al chat confirma que el servidor quedó conectado
// claude_desktop_config.json
{
  "mcpServers": {
    "powerbi-modeling": {
      "command": "npx",
      "args": ["-y",
        "@microsoft/powerbi-modeling-mcp@latest",
        "--start"]
    }
  }
}
Reinicia Claude Desktop después de guardar el archivo
Opción B · Claude Code

Claude Code

  • Claude Code registra servidores MCP desde la terminal, sin editar JSON a mano
  • Comando: claude mcp add powerbi-modeling -- npx -y @microsoft/powerbi-modeling-mcp@latest --start
  • Dentro de una sesión, escribe /mcp para ver el estado de conexión y las herramientas disponibles
  • El alcance por defecto es local a ese proyecto; usa --scope user para tenerlo en todos tus proyectos
# Terminal
claude mcp add powerbi-modeling \
  -- npx -y @microsoft/powerbi-modeling-mcp@latest \
  --start
Escribe /mcp dentro de Claude Code para confirmar la conexión
Opción C · ChatGPT / Codex

ChatGPT desktop y Codex

  • La app de escritorio de ChatGPT, Codex CLI y la extensión de IDE comparten una misma configuración MCP
  • App: Configuración → Servidores MCP → Añadir servidor → STDIO
  • CLI: codex mcp add; o edita ~/.codex/config.toml
  • ChatGPT en la web no lee esta configuración local: usa la app de escritorio o Codex
# ~/.codex/config.toml
[mcp_servers.powerbi-modeling]
command = "npx"
args = ["-y",
  "@microsoft/powerbi-modeling-mcp@latest",
  "--start"]
Escribe /mcp en Codex para confirmar la conexión
Primer arranque

EULA y conexión al modelo

  • EULA son las siglas de "acuerdo de licencia de usuario final": son los términos de uso de Microsoft, los mismos que aceptas al instalar cualquier programa
  • El servidor bloquea todas sus herramientas hasta que lo aceptas — es su forma de asegurarse de que lo leíste antes de dejarte conectar al modelo
  • En el taller: la primera vez que te conectes, la IA te va a mostrar el acuerdo y preguntarte si lo aceptas, antes de seguir
  • También se puede aceptar de antemano (con un argumento o una variable), para no tener que confirmarlo cada vez que abres una sesión

Para profundizar

Power BI Desktop Bridge

  • Qué es: un servidor que vive dentro del propio Power BI Desktop y deja que un programa externo (como un agente de IA) le hable directamente, sin pasar por internet
  • Para qué sirve: después de que la IA edita el reporte (PBIR), le pide a Desktop que recargue los cambios y tome una captura — así "ve" cómo quedó el visual, sin que tú reabras el archivo a mano
  • Ya vimos sus comandos (status, reload, screenshot-all) en la sección de Software — aquí lo retomamos como ejemplo real de cómo la IA cierra su propio ciclo de prueba

Para profundizar

Power BI Report skill

  • Qué es: un skill de Microsoft — reglas en Markdown, como un CLAUDE.md ya armado por ellos — para planear, diseñar, crear y validar reportes completos. No es un MCP ni un CLI aparte
  • Para qué sirve: mientras el MCP de modelado maneja tablas, medidas y DAX, este skill maneja la capa de reporte — páginas, visuales, formato — y valida con su propio CLI interno
  • Se instala como plugin del marketplace "Skills for Fabric" (no con npm): es la versión oficial de Microsoft de lo que nosotros armamos a mano con CLAUDE.md/AGENTS.md, pero para reportes
